# R-universe of tok-lang-bpm

The registry of https://tok-lang-bpm.r-universe.dev: the R package [tokr](https://github.com/tok-lang-bpm/tokr), which gives R the engine of the [tok](https://github.com/tok-lang-bpm/tok) process language.

```r
install.packages("tokr", repos = c("https://tok-lang-bpm.r-universe.dev", "https://cloud.r-project.org"))
```
